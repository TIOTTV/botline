# Botline

Bot Discord. Il crée des salons, affiche des boutons et répond aux gens.

## Sur Replit

1. Secrets : `DISCORD_TOKEN` = le jeton du bot.
2. Run.
3. La console affiche le lien pour inviter le bot.

Dans le portail Discord, onglet Bot, active Message Content Intent.

Dans un salon : `!menu`, ou mentionne le bot.
